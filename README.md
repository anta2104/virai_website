# Website Virai — virai.com.vn

Landing page giới thiệu công ty Virai (Astro + Tailwind, static site).

## Lệnh thường dùng

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # output: dist/
npm run preview  # xem bản build
```
